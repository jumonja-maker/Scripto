# ScriptoLib — RoadMap

Дата: 26 октября 2026 года. Программа прежде всего для личного использования на Windows, с приоритетом офлайн-библиотеки и надёжного воспроизведения.

Работаем по одному шагу: реализация → проверка → проба пользователем → исправления → следующий шаг. По дополнительному требованию первый шаг включает основу установки, обновления и удаления программы. После этой основы функции воспроизведения и онлайн-доступа добавляются по одной. Пройденные автоматические проверки и личная проверка на Windows отмечаются отдельно. Наличие расширения `.mkv` или `.mp4` в каталоге не означает, что содержимое уже проверено плеером.

## Порядок функций

| Шаг | Одна основная функция | Условие завершения | Состояние |
|---|---|---|---|
| M1 | Основа программы: локальная библиотека и жизненный цикл установки | Импорт и сохранение каталога; выбор папки установки; кнопка проверки обновлений; удаление программы с сохранением медиа | Реализовано для пробной сборки; Windows-проверка ожидается, см. CHECKS.md |
| M2 | Воспроизведение локального видео | Из библиотеки открывается файл; работают запуск, пауза, остановка и громкость; проверены звук, изображение и аппаратное декодирование на Windows | Следующий шаг |
| M3 | Перемотка | Переходы по длинному фильму не зависают и не вызывают устойчивого рассогласования звука и видео | Запланировано |
| M4 | Продолжение просмотра | После перезапуска предлагается сохранённая позиция нужного файла | Запланировано |
| M5 | Выбор звуковой дорожки | Доступные дорожки имеют понятные подписи и переключаются без перезапуска программы | Запланировано |
| M6 | Субтитры | Проверены встроенные и внешние субтитры, кириллица и выключение показа | Запланировано |
| M7 | Группировка сериалов | Один сериал содержит сезоны и серии в правильном порядке; ошибочное распределение можно исправить | Запланировано |
| M8 | Музыкальная библиотека | Квадратные обложки и список треков читаются в общей теме; выбранный локальный трек воспроизводится | Запланировано |
| M9 | Музыкальная очередь | Треки последовательно играют в фоне при переключении разделов; очередь можно изменить | Запланировано |
| M10 | Скачивание по ссылке | Одна проверенная площадка; готовый файл появляется в библиотеке только после успешного завершения | Запланировано |
| M11 | Очередь загрузок | Ошибка одной задачи не останавливает остальные; состояния и повтор понятны | Запланировано |
| M12 | Встроенный раздел YouTube | Проверены переходы, вход при необходимости и передача поддерживаемой ссылки загрузчику | Запланировано |
| M13 | Встроенный раздел VK | Самостоятельная кнопка сбоку; просмотр и доступные загрузки проверены отдельно | Запланировано |
| M14 | Встроенный раздел VK Видео | Самостоятельная кнопка сбоку; проверены реальные ссылки и поведение при ошибках | Запланировано |
| M15 | Встроенный раздел VK Видео Live | Самостоятельная кнопка сбоку; записи и прямой эфир проверяются отдельно | Запланировано |

При M10 каждая следующая площадка добавляется отдельным изменением с собственной проверкой. Скачивание музыки VK и запись прямого эфира не считаются автоматически поддержанными из-за наличия видео-загрузчика. Отдельный шаг для них определяется после проверки доступных возможностей.

## Постоянные правила интерфейса

- Основа — [одобренный макет библиотеки](https://www.figma.com/design/oyFQDV630G9wBYB8xAVHSv?node-id=2-2): почти чёрный тёмно-синий фон, белые контурные иконки, узкая боковая панель, спокойные состояния выбора.
- Новая функция добавляет только необходимые для неё элементы. Дополнительные действия прячутся в меню, когда не нужны постоянно.
- Фильмы получают постеры, видео — горизонтальные превью, музыка — квадратные обложки и список треков. Пустая библиотека содержит понятное действие добавления файлов.
- YouTube, VK, VK Видео и VK Видео Live — разделы в боковой панели. Вход относится к соответствующему сайту; для локальной библиотеки он не требуется.
- Неработающие функции не выглядят готовыми. Плеер не запускает скачивание, библиотека не требует доступности сайтов.
- В настройках есть отдельная кнопка «Проверить обновления». Проверка выполняется по нажатию; отсутствие сети показывает понятное состояние и не мешает библиотеке.

## Установка и расположение данных

Установщик должен позволять выбрать папку. Для первого запуска выбирается доступная пользователю для записи папка без прав администратора. До установки проверяется доступность записи; программа не должна молча переносить данные в AppData, если выбранный путь недоступен.

Все файлы, которыми управляет ScriptoLib, располагаются внутри выбранной папки установки. Предусмотрена следующая структура; точный состав установщика проверяется по собранному артефакту.

| Внутри выбранной папки | Назначение |
|---|---|
| `ScriptoLib.exe`, `current.txt` | Запуск и указатель текущей версии |
| `versions/<версия>/runtime`, `versions/<версия>/app` | Зависимости и код конкретной версии |
| `data` | Каталог, настройки и логи |
| `cache` | Кэш Qt/QML, временные файлы и данные обновления |
| `media` | Скачанные медиа; сохраняются при удалении программы |
| `.scriptolib-install.json` | Метка установки для проверки принадлежности служебных файлов |

Добавленные в библиотеку существующие медиа остаются по своим исходным путям; импорт не создаёт копий и не делает их собственностью установщика. Программа не требует системной регистрации и не создаёт ярлыки вне выбранной папки.

Скачанные медиа размещаются в `media`, который исключается из удаления. Деинсталлятор проверяет метку установки и удаляет принадлежащие программе файлы и служебные данные, сохраняя скачанные фильмы, серии, музыку и видео. Он также сохраняет неизвестные и созданные пользователем элементы в корне папки и не удаляет исходные медиа, добавленные из других папок. Нельзя реализовывать это рекурсивным удалением всей папки установки.

Это правило относится к файлам, создаваемым самой программой и поставляемыми компонентами. Системные следы Windows, антивируса, драйверов и проводника не контролируются ScriptoLib; обещание «никаких следов нигде вне папки» было бы неверным.

Кнопка проверки обновлений и фактическая установка новой версии имеют разные результаты проверки. До публикации настоящего релиза сообщение «обновлений нет» не заменяет сообщение «релиз ещё не опубликован». Скачанный пакет не должен исполняться без проверки источника и целостности. Выход новой версии не должен менять каталог и удалять медиа.

## CHECKS — проверка M1

Фактический результат запуска проверок фиксируется в отчёте к изменению. Следующий список задаёт критерии и сам по себе не означает, что они уже пройдены.

| Проверка | Ожидаемый результат |
|---|---|
| Первый запуск без интернета | Открывается пустая библиотека; нет обязательного входа |
| Добавление нескольких локальных файлов | Появляются записи с корректными именами и типами |
| Кириллица, пробелы и длинные имена | Имена читаются, путь не теряется |
| Повторный импорт того же файла | Вторая запись не появляется |
| Смешанный набор: допустимый, пустой, отсутствующий и неподдерживаемый файл | Допустимый добавляется; по остальным есть понятный результат |
| Закрытие и повторный запуск | Записи и выбранные категории сохраняются |
| Удаление записи из каталога | Сам файл на диске остаётся нетронутым |
| Перемещение или удаление файла вне программы | Каталог не падает; недоступность отражается при предусмотренной проверке |
| Окно обычного и минимального размера | Основные действия видны; названия не перекрывают соседние элементы |
| Выбор доступной папки установки | Программа запускается без прав администратора; служебные данные появляются внутри выбранной папки |
| Недоступная для записи папка | Понятная ошибка; нет скрытого переноса данных в AppData |
| Проверка обновлений без сети, без опубликованного релиза и с доступной новой версией | Три различимых результата; библиотека остаётся доступной |
| Контроль файлов после запуска и проверки обновлений | Приложение не пишет свои данные в AppData или системную временную папку |
| Удаление программы с тестовыми медиа | Приложение и служебные данные удалены; `media`, внешние импортированные медиа и неизвестные элементы в корне сохранились |

Пользовательская проверка M1: установить в выбранную папку, добавить несколько своих файлов, перезапустить программу, открыть настройки и проверить обновления. Оценить размеры карточек, читаемость, отступы и удобство выбора. Проверку деинсталлятора выполнять сначала на копиях тестовых медиа. Только после исправления замечаний переходим к M2. В M1 нет встроенного воспроизведения, скачивания медиа и открытия сайтов. Готовность установщика и обновления отмечается только после проверки конкретных собранных артефактов.

## Ближайшее решение

До M2 выбрать воспроизводящий движок по [плану проверки плеера](PLAYER_EVALUATION.md). Предварительный кандидат — libmpv; окончательный выбор зависит от настоящих локальных файлов и проверки на Windows. Сейчас дополнительные движки не подключаются.
