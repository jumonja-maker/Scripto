# Проверка ScriptoLib 0.1.0 — M1

Дата: 26 октября 2026 года. Этот документ отделяет выполненные проверки от
проверок на пользовательском Windows-компьютере.

## Выполнено

- `python -B -m pytest -q`: **94 теста прошли** в Linux-среде разработки.
- Реальное QML-окно загрузилось и отрисовалось в offscreen-режиме при 900×640
  и 1440×1000. Проверены пустой экран, импорт, поиск, список, карточка файла,
  настройки и кнопка проверки обновлений. Ошибок QML не обнаружено.
- Каталог: сохранение между открытиями, кириллица, повторные пути, смешанная
  партия с ошибками, смена раздела, удаление записи без удаления медиа.
- Хранение: локальные пути, недоступная для записи папка, внешние ссылки,
  настройки/логи/временные файлы; нет автоматического переноса в профиль.
- Обновление: контроль SHA256, опасные ZIP-пути, отмена, ограничение размера,
  сохранение исходной версии, подтверждение нового запуска, откат, защита
  транзакции и очистка. Процессы в тестах подставные: это **не** запуск Windows.
- Проверено наличие используемых QML-модулей и Qt-библиотек в Windows-пакете.
- Оригинальные SVG-иконки сохранены локально; шрифт Manrope включён с OFL.
- Нативные компоненты Windows компилируются с `-Wall -Wextra -Werror`.
- Оставшийся после прерывания установки внутренний модуль очищается только по собственной метке; занятые и неизвестные файлы сохраняются.
- `git diff --check` проходит.
- Независимый обзор выявил и помог исправить гонку очистки/загрузки обновления,
  повторное удаление частично удалённой версии, сохранение данных для повтора
  удаления, блокировку обслуживания, цикл перезапуска при несовпадении версий
  и отдельные пути кэшей Qt, которые нельзя контролировать только через XDG.

## Требует Windows

- Запуск конкретного `Setup.exe`, выбор папки, установка без прав администратора.
- Запуск встроенного Python/Qt на целевой Windows и проверка масштабирования.
- Трассировка операций файловой системы: отсутствие управляемых приложением
  файлов вне папки установки, включая установку и удаление.
- Настоящее обновление между двумя опубликованными версиями, остановка/откат
  процессов, блокировка файлов антивирусом и повтор после неудачи.
- Запуск `Uninstall.exe`, сохранение тестовых медиа и удаление самого uninstall.

## Ограничения первой версии

Встроенный плеер ещё не подключён: расширение файла означает только допуск в
каталог. Постеры не подменяются демонстрационными фильмами; пока используются
нейтральные карточки файлов. Онлайн-площадки и загрузка медиа следуют отдельными
этапами RoadMap.

Проверка обновлений работает по запросу. Для полноценного испытания доставки
нужен следующий GitHub Release с предоставленным GitHub полем SHA256 asset.
SHA256 подтверждает целостность пакета, а не является цифровой подписью кода.
При неоднозначной аварии запуска helper сохраняет обе версии и приостанавливает
очистку; порядок восстановления описан в UPDATE_PROTOCOL.md. Полная проверка
аварийного выключения питания не заявляется.

Все файлы, которые создаёт ScriptoLib, спроектированы для хранения внутри
установки. Системные следы Windows, антивируса и драйверов отдельно от этого
правила и не могут быть полностью устранены приложением.
