ScriptoLib 0.1.1 — небольшое исправление интерфейса M1.

- Исправлены иконки переключения карточек и списка.
- Убран второй поиск из боковой панели.
- Категории стали компактнее; поиск и добавление файлов собраны в верхней панели.

Это пока локальная библиотека файлов. Встроенный плеер и загрузка медиа ещё не
подключены. Для первой установки нужен `ScriptoLib-0.1.1-Setup.exe`; ZIP
`ScriptoLib-0.1.1-windows-x64.zip` предназначен для кнопки обновления в настройках.

Тесты приложения, QML и протокола публикации выполняются автоматически в Linux.
Windows-компоненты собраны MinGW. Установка, настоящее обновление и удаление
этой сборки на реальной Windows ещё не подтверждены. Исполняемые файлы не имеют
цифровой подписи. Канал stable используется для доставки через встроенное
обновление и не означает завершённость программы.
