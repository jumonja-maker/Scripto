# Установка и удаление ScriptoLib

Первый пакет предназначен для Windows 10/11 x64. Python и Qt включены в установщик: отдельно устанавливать Python не требуется. Проверку на реальном Windows-компьютере отмечаем отдельно от успешной сборки установщика.

## Установка

1. Открыть `ScriptoLib-0.1.1-Setup.exe` из опубликованного релиза.
2. В окне выбора создать или выбрать **отдельную пустую папку**, доступную пользователю для записи, например `D:\ScriptoLib`.
3. После установки открыть `ScriptoLib.exe` в этой папке.

Установщик работает без запроса прав администратора. Папка `Program Files` обычно не подходит: библиотека и обновления должны иметь право записи рядом с программой. Повторная установка поверх непустой папки запрещена; обновление существующей установки выполняется через настройки программы.

Ярлыки на рабочем столе, записи в меню «Пуск», регистрация в системном списке приложений и ассоциации файлов не создаются. Это сознательное следствие требования хранить управляемые приложением файлы в одной папке.

Внешний нативный установщик выбирает папку до создания собственных файлов. После выбора он распаковывает внутренний NSIS-движок в `cache/setup`, задаёт дочернему процессу `TEMP` и `TMP` в этой же папке и показывает ход установки. Даже служебная проверка временной папки самим NSIS остаётся внутри выбранного каталога. После завершения внутренний движок и его пустая временная папка удаляются. Исходный скачанный `Setup.exe` остаётся там, куда пользователь его скачал.

После удаления папка может остаться с сохранённым `media`. Для повторной установки первой версии следует выбрать новую пустую папку и затем добавить сохранённые медиафайлы в библиотеку. Установщик не перезаписывает такую непустую папку автоматически.

## Содержимое папки

| Путь | Назначение |
|---|---|
| `ScriptoLib.exe` | Небольшой постоянный запускатель |
| `Uninstall.exe` | Удаление программы с сохранением медиафайлов |
| `current.txt` | Номер активной версии |
| `versions/<версия>/runtime` | Встроенные Python и Qt |
| `versions/<версия>/app` | Код, интерфейс и документация программы |
| `data` | Каталог, настройки и служебное состояние |
| `cache` | Временные файлы и подготовка обновлений |
| `media` | Предусмотренная папка будущих загрузок; сохраняется при удалении |

Импорт файлов в библиотеку сохраняет ссылки на существующие файлы. Он не копирует, не переносит и не изменяет фильмы или музыку. Файлы, расположенные вне папки программы, остаются на исходных местах.

ScriptoLib не должна самостоятельно создавать данные в AppData, системной Temp или домашней папке. Системные следы Windows, антивируса и драйверов приложение полностью контролировать не может.

## Удаление

1. Закрыть ScriptoLib.
2. Открыть `Uninstall.exe` из папки установки.
3. Подтвердить удаление приложения, каталога, настроек и кэша.

Удаление использует список принадлежащих программе файлов каждой версии. Оно не выполняет рекурсивное удаление всей выбранной папки. Папка `media` и посторонние файлы в корне сохраняются; исходные медиафайлы вне установки не затрагиваются. Каталоги `data` и `cache` предназначены только для служебных данных приложения — личные файлы следует хранить в `media` или в собственных папках.

Ссылки/junction не обходятся при удалении. При обнаружении занятых или неоднозначных файлов удаление сообщает о проблеме. Если после аварии остался файл блокировки, нужно запустить и нормально закрыть ScriptoLib перед повторным удалением.

Обычный NSIS-uninstaller копирует себя в системную Temp. Поэтому здесь используется собственный небольшой нативный `Uninstall.exe`, работающий на месте. Для удаления последнего собственного исполняемого файла он запускает системный `cmd.exe` с точным путём через переменную окружения; временный скрипт и запись в реестре не создаются. Папка установки после удаления может остаться с медиафайлами.

## Сборка разработчиком

Нужны Python 3.12+, MinGW-w64 и NSIS. На Linux:

```bash
python scripts/build_windows.py --version 0.1.1
```

Можно явно указать пути к инструментам через `--cc`, `--windres`, `--makensis`, `--nsisdir`, а также каталог зависимостей `--cache` и выходной каталог `--output`.

Скрипт проверяет SHA256 закреплённых Windows-зависимостей, собирает два нативных запускателя, формирует пакет приложения, установщик и `SHA256SUMS.txt`. ZIP `ScriptoLib-<версия>-windows-x64.zip` предназначен для механизма обновления; пользователю для первой установки нужен файл `Setup.exe`.

Пакет включает доступные лицензионные файлы зависимостей. Перед публичным стабильным выпуском проверяются комплект уведомлений и выполнение условий распространения выбранной сборки Qt.

Официальные источники: [Python embedded distribution](https://docs.python.org/3.12/using/windows.html#the-embeddable-package), [NSIS: переменные и удаление](https://nsis.sourceforge.io/Docs/Chapter4.html), [NSIS: параметр предотвращения копирования uninstaller в Temp](https://nsis.sourceforge.io/Docs/Chapter3.html#installerusagecommon).
