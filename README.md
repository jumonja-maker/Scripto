# ScriptoLib

Минималистичная личная медиатека для Windows с приоритетом офлайн-работы.
Основа оформления — [выбранный макет «Библиотека»](https://www.figma.com/design/oyFQDV630G9wBYB8xAVHSv?node-id=2-2).

## Первый этап — 0.1.0

Добавление локальных видео и музыки, сохранение каталога, поиск, разделы,
карточки и список. Добавленные файлы остаются на своих местах. Удаление записи
из библиотеки не удаляет сам файл. В настройках есть проверка обновлений.

Встроенный плеер — следующий отдельный этап. В этой версии нет воспроизведения,
скачивания медиа или встроенных сайтов. Наличие файла в каталоге пока не
подтверждает возможность его декодирования.

## Установка

Пробная сборка: `ScriptoLib-0.1.0-Setup.exe`, Windows x64. Python и Qt включены.
Выберите отдельную пустую папку с правом записи, например `D:\ScriptoLib`.
Запуск: `ScriptoLib.exe` в выбранной папке. Удаление: `Uninstall.exe` рядом.

Все управляемые приложением данные остаются внутри установки: каталог и
настройки в `data`, временные файлы в `cache`, будущие скачанные медиа в `media`.
Удаление сохраняет `media`, внешние исходные файлы и неизвестные файлы в корне.
Ярлыки и системная регистрация не создаются. Системные следы Windows и
антивируса не находятся под контролем приложения.

Обновление проверяется только по нажатию. Скачанный пакет проверяется по
SHA256, запускается как новая версия, затем удаляется предыдущая. Если запуск
не подтверждён, восстанавливается предыдущая версия. Пока в GitHub Releases
нет следующего релиза, проверить реальную доставку обновления нельзя; аварийные
ветки протокола проверяются автоматическими тестами.

## Что проверить первым

1. Установить в выбранную папку и открыть программу.
2. Добавить несколько видео и музыкальных файлов, в том числе с кириллицей.
3. Повторно добавить тот же файл — дубликат не должен появиться.
4. Найти файл поиском, назначить видео раздел «Фильмы» или «Сериалы».
5. Закрыть и открыть программу — каталог должен сохраниться.
6. В настройках нажать «Проверить обновления».
7. Для проверки удаления положить **копию** тестового медиафайла в `media`,
   закрыть приложение и запустить `Uninstall.exe`. Копия должна остаться.

Сборка установщика и работа на реальном Windows — отдельные проверки.

## Запуск из исходников

Python 3.12+, зависимости из `pyproject.toml`. Для разработки:

```sh
python -m venv .venv
# Windows: .venv\Scripts\python.exe вместо .venv/bin/python
.venv/bin/python -m pip install -e . pytest
.venv/bin/python -B bootstrap.py --root .
.venv/bin/python -B -m pytest -q
```

Пакет Windows собирается `python scripts/build_windows.py`; инструменты и
параметры описаны в инструкции установки. Автоматические GitHub Actions в
этом этапе не добавлены.
